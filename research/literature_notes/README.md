**Conventions used in the notes:**

- An item is included only if its page was fetched.
- "Content note", **[V-meta]** or **†** means the bibliographic metadata was verified, but the summary is based on knowledge of the paper (for example, when the ACM DL returned HTTP 403).
- **[U]** marks an unverified detail.
- The phrase "AgentPause would differ by…" was written *before* implementation and records the intended design.

The curated, deduplicated version is [`../prior_art.md`](../prior_art.md). Where the two
disagree, `prior_art.md` is authoritative.
